# Vencord auto patcher written in rust

> [!NOTE]
> This project was inspired by [this repository](https://github.com/dtcesu/VencordAutoPatcher)

## Features

- Easy to install
- Automatically adds to autostart
- Starts discord after patching
- Written in rust

## Instalation

1. Download `VencordAutoPatcher.exe` from releases page
2. Start the program
3. Type `1` and press `Enter`

## Contributing

1. Install rust
2. Install Build tools for C++ or Visual Studio
3. Clone the repo

```
git clone https://github.com/chorus4/VencordAutoPatcher
```

4. Start the program

```
cargo run
```

5. Compiling

- For test release

```
cargo build
```

- For production

```
cargo build --release
```
